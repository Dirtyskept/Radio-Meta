Radio Meta WebLoader — nowplayingbar.js integration note
========================================================

Release v1.3.96 does not modify nowplayingbar.js. This note documents the
existing loader pointer shipped in the WebLoader package for users who choose
to install the integration. The installer verifies the target hash and requires
explicit confirmation before replacing the file.

File: modules/nowplayingbar/nowplayingbar.js
Purpose: Minimal AMD pointer to the loader embedded in RadioMeta.dll.

Existing added code:
/* Radio Meta DLL loader pointer; implementation is embedded in RadioMeta.dll. */
;(function () {
    var p = String(window.location && window.location.pathname || "/");
    var i = p.toLowerCase().lastIndexOf("/web/");
    window.require([(i >= 0 ? p.slice(0, i) : p.replace(/\/web$/i, "")) +
        "/web/ConfigurationPage?name=RadioMetaDisplayLoader.js"]);
}());
