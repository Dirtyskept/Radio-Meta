RADIO META v1.3.154 — START HERE

This is the Radio Meta source package, not a compiled DLL.

1. Read WHAT-RADIO-META-CHANGES-IN-EMBY.txt. Radio Meta adds one marked script
   block to Emby's web start page; that file explains exactly what and why.
   WHAT-RADIO-META-CHANGES-IN-THE-WEB-PLAYER.txt lists what the player script
   changes in the web app while a page is open.
2. Extract the complete ZIP.
3. Open PowerShell in the extracted RadioMeta-v1.3.154 folder.
4. Run: .\Build-RadioMeta154.ps1
   It builds against RadioMeta\EmbyReferences\4.10.2 (copy three Emby DLLs
   there once: RadioMeta\EmbyReferences\README.txt), so the DLL also loads on
   older Emby versions back to 4.10.2.
5. Back up your working RadioMeta.dll before replacing it.
6. After installing, press Ctrl+F5 once in each browser.

README.md describes the plugin.
