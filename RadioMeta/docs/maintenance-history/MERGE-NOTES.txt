Merge approach
--------------
Unchanged v1.3.97 source files were retained. Source files changed in the v1.7.9
donor were overlaid selectively, and new proxy/hardening source files were added.
The WebLoader payload and installer/restore scripts match the v1.3.97 baseline.
The dashboard bundle was synchronized with the current 15 ordered dashboard
source sections.

Included changes
----------------
- Optional FFmpeg proxy for selected .strm stations and immediate per-station
  proxy on/off control.
- Targeted library refresh on Create .strm, successful Save changes, and proxy
  enable/disable.
- Proxy-enabled station edit lock enforced in both dashboard and API.
- Admin-role requirements for management/configuration APIs, while preserving
  authenticated-only CurrentTracks access for dashboard/player compatibility.
- Proxy client/process limits, bounded reads, URL/sidecar validation, safer
  public-host logo downloading, sanitized FFmpeg logging, and bounded metadata
  caches.
