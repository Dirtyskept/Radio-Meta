Station Metadata Settings

Enter an exact .strm title to target one station, or an exact Emby device name (for example, Safari iOS) to target every station playing on that device. Station-specific rules take priority over device-wide rules. Station delay shows the first valid current song immediately when you tune in, then waits for the configured delay before publishing later song/artist changes. Disable metadata skips song lookups. Carplay keeps its existing device-specific station-change behavior. Delay 0 means off.

Ignore Metadata Phrases

Add text that should not be treated as a song title, such as station slogans or status messages. Matching is case-insensitive and ignores a candidate when the phrase appears anywhere in its metadata. Leave Station blank to apply a rule to every station. Use specific phrases: any song containing a configured phrase will be ignored. Up to 100 rules can be saved. Changes are stored in the plugin's XML configuration.
